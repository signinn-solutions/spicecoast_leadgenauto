# SpiceCoast · B2B Lead Automation & AI Mailbox

An automated lead generation, enrichment, and AI email responder platform tailored for **SpiceCoast**, combining:
1. **Google Places API** (Text Search v1) for targeted B2B lead discovery.
2. **Hunter.io API** for email extraction and deliverability verification.
3. **DeepSeek AI + Hostinger Agentic Mail API** for automated inbound lead response drafting and webhook dispatch.
4. **Interactive Web Dashboard** (React 18 + Vite + Recharts).

---

## Features
- **Lead Discovery & Verification**: Find businesses by keyword/location, retrieve domain contacts, and verify email deliverability (`deliverable`, `risky`, `undeliverable`).
- **AI Mail Auto-Responder**: Inbound emails received via Hostinger Mail Webhook are parsed, filtered for sales intent, and drafted automatically via **DeepSeek API** (`deepseek-chat`).
- **Hostinger Agentic Mail Dispatch**: Automatic or reviewed 1-click dispatch directly through Hostinger's REST API.
- **Quota & Budget Guards**: Daily limits on lead searches (50/day) and AI auto-replies (30/day) with calendar-day auto resets.
- **SpiceCoast Design System**: Dark obsidian palette (`#17140f`) with warm turmeric, paprika, and cardamom accents.

## Getting Started

### 1. Install Dependencies
```bash
# Python backend dependencies
pip install -r requirements.txt

# Frontend dependencies
npm install
```

### 2. Configure API Keys
Create or edit `.env` in the root directory:
```env
# Google Cloud Places API Key
GOOGLE_API_KEY=your_google_places_api_key

# Hunter.io API Key
HUNTER_API_KEY=your_hunter_api_key

# DeepSeek API (for AI mail response drafting)
DEEPSEEK_API_KEY=your_deepseek_api_key
DEEPSEEK_MODEL=deepseek-chat

# Hostinger Agentic Mail API & Webhook
HOSTINGER_API_TOKEN=your_hostinger_agentic_mail_api_token
HOSTINGER_WEBHOOK_BEARER_TOKEN=your_hostinger_webhook_bearer_token
SENDER_MAILBOX=outreach@thespicecoast.com
AUTO_SEND=false
DAILY_REPLY_LIMIT=30
```

### 3. Run the Web Application
```bash
# Run full stack (Flask API + Vite UI concurrently)
npm start
```
- Dashboard UI: `http://localhost:3000`
- Backend API: `http://127.0.0.1:5001`
- Hostinger Webhook Endpoint: `http://127.0.0.1:5001/webhook` (or behind HTTPS in production)

---

## Webhook Setup (Hostinger Mail)
1. Go to **hPanel -> Emails -> [your-domain] -> Agentic mail -> Webhooks**.
2. Set Webhook URL to: `https://your-domain.com/webhook`
3. Copy the Bearer Token generated by Hostinger into `HOSTINGER_WEBHOOK_BEARER_TOKEN` in `.env`.
